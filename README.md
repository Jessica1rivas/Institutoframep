# FRAME · Valla publicitaria con QR

Sitio estático (HTML, CSS y JavaScript) del trabajo *Diseño de Productos Innovadores de Comunicación Visual* – SENATI Río Negro.

## Estructura
- `index.html` · `styles.css` · `script.js`
- `imagenes/` · imágenes en WebP

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube **el contenido** de esta carpeta (que `index.html` quede en la raíz).
2. Ve a **Settings → Pages**.
3. En *Build and deployment* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera un minuto: el sitio quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Las tipografías se cargan desde Google Fonts, por lo que se necesita conexión a internet.
